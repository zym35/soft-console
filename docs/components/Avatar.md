# Avatar

An avatar shows the signed-in person's initials on a convex disc.

## What you provide
```html
<span class="sc-avatar sc-raised-1">K</span>
```
A 32px disc with the `surface-up` to `surface-down` gradient and initials in `accent-text`.

## Do and don't
- Do use one or two initials.
- Don't make it a button without an accessible label.
